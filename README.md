# Quarto Academic Website

Clone the repository and navigate to the project folder in the terminal and set the currend working directory to the project folder.

- [**Render**](https://quarto.org/docs/websites/) your site locally by issue the following command in the terminal:
  ```
  quarto render
  ```
- **Workflow:** Preview your site by issuing the following command in the terminal and follow live changes to the files:
  ```
  quarto preview
  ```

## 🛠 Requirements

- Install [Quarto](https://quarto.org/docs/get-started/)
- Learn the basics from the [official Quarto documentation](https://quarto.org/docs/guide/)
- Try publishing the site *before* making major changes to confirm it runs correctly
